## Audit

The v0.1 app is a small static ES-module PWA. Useful foundations: stable IDs, truthful unsupported state, textContent rendering, feature detection, four deterministic contract tests, relative hosting paths. Deficits: only one runnable tool, no input workflow/copy, disabled/planned cards dominate, SVG-only manifest, service worker intercepts third-party traffic and deletes every unrelated origin cache.

## Decisions

1. Retain dependency-free ES modules and status grammar; add generic public adapters in tools.js. No server framework or private networking source in public code.
2. First coherent increment is My Connection + Public IP + DNS + IPv4 subnet calculation. Category filters and search scale beyond the original deck. Native requirements live in one explanatory disclosure, not many disabled cards.
3. Explicit outbound calls only after submit; show provider disclosure, bound duration, cancel and preserve input. Do not silently fail over providers or address families.
4. Computation and observations are distinct: CIDR input is user-supplied, not an OS-observed interface. /31 point-to-point and /32 host route omit directed broadcast.
5. Cache a versioned shell only; external responses bypass the worker. Waiting activation avoids mixing adapter versions. Remove only Network Knackers caches. PNG install icons supplement the SVG favicon. In-memory input drafts survive tool navigation; no durable history.
6. Publish only the requested development preview to existing GitHub Pages; commercial production launch remains a separate human decision.

## Next increments

Reverse lookup with IPv4/IPv6 reverse-name generation → port/service reference → resolver comparison → RDAP. Review provider CORS, terms and privacy per increment. Arbitrary HTTP/TLS inspection needs a minimal separately reviewed backend with public-target restrictions, SSRF controls, rate limits, timeouts and truthful remote vantage. Native/desktop roadmap remains in the private repo, aligned by catalogue IDs.

## Known debt / acceptance

Physical phone install, live-provider browser CORS, responsive visual QA and service-worker update runtime checks need evidence. Local Chromium installation was blocked by a truncated download in the execution environment; do not mistake source tests for browser acceptance. Keep UI labels explicit about preview status.
