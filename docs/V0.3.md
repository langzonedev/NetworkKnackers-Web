## Added capabilities

| ID | Input → output | Activity / provenance | Other-platform mapping |
|---|---|---|---|
| dns.reverse | IPv4/IPv6 → reverse query, PTR response | Active, Cloudflare DoH | Future selectable/native resolver adapter |
| dns.compare | name/type → two response codes and record sets | Active, Cloudflare + Google DoH | Future resolver comparison, same output semantics |
| ipv6.prefix | IPv6/prefix → expanded input, prefix, exact range/count | Local calculation, no network privilege | Generic local math on all platforms |
| port.reference | port/service + TCP/UDP/Any → common-use entries | Local reference, no scanning | Same curated reference; not a service detector |
| url.inspect | HTTP(S) URL → components and repeated query parameters | Local calculation; does not open destination | Generic parser; remote inspection remains separate |
| json.format | text + pretty/minified → validated formatted JSON | Local transformation; preserves number spelling, duplicate keys and escapes | Shared behavioural contract |
| base64.convert | text + encode/decode → UTF-8/Base64 text | Local transformation; standard padded Base64, no binary/file decoding | Shared behavioural contract |
| hash.text | text + SHA-256/384/512 → hexadecimal digest, byte count | Local Web Crypto, HTTPS required | OS/platform crypto adapters later |

The existing four tools remain. New public metadata lives in extra-tools.js, composed alongside existing webTools in capabilities.js. New result field kind `reference` marks reference entries. Inputs may declare `multiline`, `required` and `action`; optional action labels make Calculate / Format / Hash / Find clearer than Run check for local tools.

## UX / privacy

Search and category filters now include Investigate and Sysadmin. A bounded scrolling toolbox prevents twelve cards pushing the task far down the phone layout. Multiline inputs, whitespace-preserving result blocks, per-value copy and JSON report export support actual sysadmin workflows. Copies/exports happen only on explicit action. Drafts/results remain in memory, with no history/sync/analytics. Local text is limited to 100,000 characters; JSON nesting is bounded at 64 and formatted output at 300,000 characters.

The DNS comparison sends one query to each named provider, uses allSettled to preserve partial evidence, normalizes record order/TTL and equivalent AAAA/domain representations, and compares DNS response codes too. It does not label differences as a failed propagation test. Google requests include `edns_client_subnet=0.0.0.0/0`; this limits ECS forwarding, not Google's visibility of the caller IP. NXDOMAIN is a successful observation of a negative response. Provider errors remain explicit.

## Sources and provider review

Reviewed official references 2026-10-29:

- [Google DNS JSON API](https://developers.google.com/speed/public-dns/docs/doh/json), [privacy](https://developers.google.com/speed/public-dns/privacy), [terms](https://developers.google.com/speed/public-dns/terms). Google is an additional explicitly disclosed provider, not an automatic fallback. No credentials or provider-derived state are stored.
- [IANA service-name/port registry](https://www.iana.org/assignments/service-names-port-numbers) and [Microsoft service port requirements](https://learn.microsoft.com/en-us/troubleshoot/windows-server/networking/service-overview-and-network-port-requirements). Port entries are a curated common-use subset, not a copy of the entire registry; deployed services can differ.
- [RFC 4291 IPv6 addressing](https://www.rfc-editor.org/info/rfc4291/) for address and prefix representations. Prefix arithmetic does not assert a usable-host count, address assignment or SLAAC suitability.
